# 作业小宠物

完成作业打卡、收集积分，再领养和照顾虚拟小宠物的家庭网页工具。

网页地址：https://cai-caisf.github.io/homework-pet/

## 使用

- 添加作业，自定义每项作业的奖励积分（正整数，默认 10 分）。
- 布置作业时可以拍照或从相册选择最多 6 张参考照片；点击缩略图可放大、缩放和切换查看。
- 点击完成打卡后，弹窗核对作业和积分，答对一道随机 2～9 乘法题（两个因数均不为 1）后再领取；答错会换新题，可一直重试，不扣分。取消不标记完成，同一项作业只能领取一次。
- 用积分领养狗狗、小猫或兔兔，购买饲料、喂食和安排出游。
- 领养后在温馨房间里查看会呼吸、眨眼和摇尾巴的小动物；喂食时会低头吃东西、咀嚼并出现爱心。
- 可以切换不同宠物，查看饱饱度、开心度和小家的日记；互动动画期间防止重复消耗饲料或积分。
- 通过页脚下载 JSON 备份或恢复备份，备份包含作业照片，兼容旧版本的文字备份。

## 大人奖励

- 首页和作业打卡页均有“大人奖励”入口。答对一道随机混合计算题后，填写奖励积分（1–1000 的整数）和奖励原因，再确认发放。
- 每次奖励需要重新验证；通过后的本次操作 5 分钟内有效。答错后需要重新答题，累计答错三次暂停 30 秒，关闭弹窗或刷新不会清除暂停。
- 奖励原因显示在最近的小故事中；单独保留最近 100 笔奖励，奖励表单中显示最近 5 笔。奖励记录包含在 JSON 备份中，兼容旧版本备份。
- 计算题用于减少误操作，无法代替家长密码；会计算或使用计算器的孩子仍可能通过。

## 每周安排与限时打卡

- 作业打卡页提供周一至周日的日期栏，可切换上周、下周、任意日期并提前安排作业。首页只统计当天安排的作业。
- 添加作业时选择主日期，并勾选其他日期；也可一键选择“周一至周五”或“整周每天”。每一天生成独立作业，分别打卡、领取积分；相同参考照片共用一份本地图片存储。
- 可选勾选“设置可打卡时间段”。时间按安排日期及设备本地时间计算，开始时刻起可打卡，到结束时刻关闭，未开始或过期均不能领取积分。确认弹窗提交时也会再次检查时间。
- 结束时间早于开始时间时，表示次日结束；开始与结束不能相同。未设时间段的作业随时可完成，包括提前完成。
- 已有未注明日期的作业，在首次升级时归入当天且默认不限时，之后不会随日期漂移。原有积分、宠物、照片和完成记录保留；日期和时间段随备份一起保存。

## 任务排序与编辑

- 作业卡片提供“上移 / 下移”，按当前日期单独调整展示顺序；首页、刷新和备份恢复沿用保存的顺序。已完成任务也可调整展示位置。
- 未完成任务可点“编辑”，在下方表单修改内容、备注、积分、日期、可打卡时间段和参考照片，再点“保存修改”；“取消编辑”保留原记录。每次仅修改这一项，不会改动同周其他日期的副本；改到其他日期后排在该日已有任务之后。
- 编辑不发放或扣除积分，任务 ID 与完成记录保留，完成时按新奖励领取一次。已完成任务不提供编辑入口，保存时也会重新检查完成状态；其他页面修改过同一任务时须重新打开编辑。
- 替换照片时保留其他任务仍在使用的图片；保存失败保留原记录及原照片，草稿可重试。切换编辑对象前会提醒确认放下未保存草稿。

## 动物盲盒领养

- 积分小铺新增动物盲盒：100 积分随机领养 1 只熊猫、小企鹅或小乌龟，三种等概率（各 1/3），可能获得同种的新伙伴。确认花费后才扣分；结果在开盒动画前保存，关闭或刷新不会丢失、重抽或重复扣分。
- 每只新伙伴有固定小名、个体配色、配饰和自己的小家；熊猫住竹林小屋，企鹅住冰雪小屋，乌龟住池塘小院。都有喂食、零食、玩具、出游和趴卧睡觉的形象与动画，原有健康度、开心度及睡觉规则适用。
- 白天可开启盲盒；22:30–06:00 暂停领养，仍可提前购买专属物品。库存按动物种类保存，同种伙伴共用，各种类之间不能混用。

| 伙伴 | 专属玩具（可反复使用） | 专属零食（每份） |
| --- | --- | --- |
| 熊猫 | 竹球 · 60 积分 | 脆嫩竹笋 · 40 积分 |
| 小企鹅 | 小小滑冰板 · 80 积分 | 鲜香小鱼 · 50 积分 |
| 小乌龟 | 彩石滚滚球 · 40 积分 | 清甜菜叶 · 30 积分 |

玩具每次开心度 +20，零食饱饱度 +25，数值最高 100%。新动物、个体身份与专属库存包含在原有 JSON / 文字备份中，旧记录升级会补齐空库存。

## 每只宠物的小名与小家

- 同种动物也有独立小名、毛色、花纹和配饰；切换列表中的头像与房间里的动物一致。喂食、玩耍、出游和趴卧睡觉均保留各自的形象。
- 每只宠物的小家有自己的布置：保留第一只的原房间，后续伙伴搭配帐篷、书架、花窗或积木屋，以及不同的墙面、窗帘和地毯颜色，并挂上名字牌。
- 旧记录自动补齐固定身份，“团团2”等默认编号名改为不同小名；已有不重复的自定义名字保留。不会更换宠物 ID，也不会重置积分、库存、成长数值或消耗速度。
- 名字和身份保存在本地及 JSON / 文字备份中。刷新、调整数组顺序或恢复新版备份后，外观与小家保持一致；旧备份在导入时补齐。

## 玩具与零食

- 积分小铺和宠物小家的专属背包均可购买；狗狗、猫咪、兔兔的玩具与零食均为 50 积分，盲盒伙伴的专属物品按上表标价。
- 狗狗：骨头响响玩具、骨头饼干；猫咪：毛线球、小鱼饼干；兔兔：萝卜滚滚球、鲜嫩菜叶。物品只适合对应动物，同类伙伴共用库存。
- 玩具购买一次即可反复使用，每次开心度 +20；狗狗抛接骨头、猫咪扑毛线球、兔兔蹦跳推球，各有对应动画。
- 零食每次消耗 1 份，饱饱度 +25，播放低头咀嚼和零食逐渐吃完的动画；已吃饱时不消耗零食。
- 数值上限 100%。开心度低于 50% 时不能喂零食，可先用玩具陪玩。每天 22:30–次日 06:00 不能使用玩具或喂零食，可以提前购买放入背包。
- 动画期间不能重复使用或切换宠物；购买扣分、物品库存和数值在开始互动时一起保存，刷新不会重复扣除。库存随 JSON 备份恢复，旧数据和旧备份默认为未购买。

## 随时间消耗

- 每天 06:00–22:30，每只宠物有固定的个体消耗速度：饱饱度每小时下降 5、6 或 7 点，开心度 3、4 或 5 点，健康度 1、2 或 3 点，速度和数值均为整数；三项分别生成小幅差异，同一种动物的不同个体也会不同，最低 0。睡觉期间三项均暂停下降。
- 差异按宠物身份固定并保存在记录中，刷新、使用道具、改名和备份恢复都不会重新抽取；饱饱度与开心度每次减少 1 点，按各自速度决定间隔；健康度每累计一个白天小时减少各自固定的 1、2 或 3 点。
- 所有已领养动物分别计算，不取决于当前查看哪一只。关闭网页、切到后台或换日期后，回到网页会根据经过的白天时间补算；夜间时段不计入。
- 不满一个扣减间隔的时间会保留，刷新、切换宠物或喂食不会使计时重新开始。数值降到 0 后，新的照顾从当前时间继续计算。
- 从统一速度版本升级时，先按原速度结算到升级时刻，再分配个体速度，剩余进度按比例保留；不会用新速度追扣升级之前的数据。
- 已有宠物和缺少计时字段的旧备份，从首次升级/导入时开始计时，不追扣升级前几天的数据。新版备份保留计时和剩余时间。
- 页面每分钟检查，重新打开、回到前台及照顾前也会核对。开心度低于 50 时仍须先陪玩再喂食。

## 健康度与健康道具

- 每只动物有独立健康度，初始为 100%。健康度按各自速度每累计一个白天小时下降 1、2 或 3 点，最低 0。22:30–06:00 暂停下降，离线后补算，刷新保留未满一小时的时间。
- 健康度达到 50% 即可喂饲料、喂零食、使用玩具、去公园或宠物乐园。低健康度时可继续切换查看、购买物品和使用健康道具；每只动物单独判断。
- 元气胶囊：30 积分/份，恢复 10 点健康度；健康针剂：50 积分/份，恢复 20 点。每次消耗一份，最高恢复到 100%；已满健康度时不消耗道具。
- 积分小铺与宠物页“健康小药箱”均可购买，所有动物共用道具库存。在药箱点击“使用胶囊”或“打针”播放恢复动画；动画期间防止重复消耗。使用后重新开始健康计时。
- 睡觉时可购买健康道具，06:00 后再使用。互动过程中健康度降到 50% 以下时会结束当前动画，先恢复健康再继续；不额外收费。
- 已有动物及不含健康度的旧备份从首次升级/导入时以 100% 健康开始，不追扣之前的健康度。健康计时与道具库存包含在 JSON/文字备份中。

## 照顾规则

- 20 积分购买 3 份饲料；每次喂食消耗 1 份，饱饱度 +10、开心度 +5，两项最高 100%。
- 开心度低于 50% 时禁止喂食，即使有饲料也不会消耗；达到 50% 后可喂食。白天去公园增加 18 点开心度，宠物乐园增加 26 点，上限 100%。
- 按设备本地时间，每天 22:30 起至次日 06:00 前睡觉，暂停喂食、零食、玩具互动、出游和领养；多只宠物可以通过左右箭头或伙伴列表切换查看，切换不会唤醒宠物或改变数值。睡眠期间可继续作业打卡、获得积分和购买饲料。
- 到 22:30 会停止当前互动动效并回到小家睡觉，不额外扣积分或饲料；06:00 自动恢复。网页重新打开、回到前台或设备时间变化时会重新检查。

## 宠物出游与睡姿

狗狗使用暖暖客厅、林荫公园和狗狗乐园；猫咪使用窗边小屋、花间公园和攀爬乐园，玩具为毛线球；兔兔使用花园小屋、草地公园和洞洞乐园，玩具为萝卜球。去公园花费 10 积分，宠物乐园花费 20 积分，小动物有对应的散步或玩耍动作。出游约 12 秒后自动回家，也可点击“回小家”提前结束，均只在出发时扣一次积分。出游期间禁用照顾和宠物切换，避免重复花费；切换到作业页后不会打断正在填写的草稿。

睡觉时使用单独绘制的趴卧形象：身体横卧、前爪垫在头下，配合缓慢呼吸和闭眼表情，三种动物均有对应睡姿。

积分不足时，不扣分也不进入出游，屏幕中央提示还差多少积分；该提示会自动消失。

## 数据

数据保存在当前设备、当前浏览器的本地存储中。不同设备和浏览器各自保存，不会自动同步；清除网站数据可能丢失记录，请定期下载备份。

作业照片适度压缩后保存在浏览器的 IndexedDB 中，图片最长边不超过 2048 像素，不会发送到服务器。手机的“拍照”入口由浏览器调用相机；电脑上可用文件选择器选图。

这个仓库只包含静态网页代码，不包含任何使用者的作业、积分或宠物记录。

## 在 iPhone / iPad 上保存和恢复备份

1. 点击页脚“下载数据备份”，等待内容准备完成。弹窗会显示文件名、作业/宠物/积分数量、照片数量及文件大小。
2. 浏览器支持时，可点“保存到文件 / 分享”，在系统面板选择“存储到‘文件’”，选好文件夹后完成存储；也可点“下载 JSON 文件”。下载链接保留至重新生成备份或刷新网页，关闭弹窗不会立即释放。
3. 没有“文件”App 或下载找不到时，点“复制备份内容”，粘贴到“备忘录”保存。若自动复制未成功，可长按显示的完整内容，选择“全选 → 复制”。较大备份优先保存 JSON 文件；用备忘录时须完整保留内容，勿编辑或截断。
4. 恢复时点“恢复备份”，选择 JSON 文件（也接受内容为 JSON 的 TXT 文件），或粘贴先前保存的完整内容。网页先检查并展示作业、宠物、积分和照片数量，点击“确认替换并恢复”才写入；取消或无效内容不会修改记录。

网页只能确认内容已准备好或浏览器接受了下载请求，不能确认 iOS 是否真正保存了文件。请在目标位置检查文件能打开，或备忘录中已保留完整内容。旧备份仍然兼容；库存、作业日期、打卡时限与照片一起恢复。

## 误删后的恢复

1. 打开网页，找到页面底部的“恢复备份”。
2. 选择之前下载的“作业小宠物备份-日期.json”文件。
3. 核对网页显示的数量，再点“确认替换并恢复”，恢复到备份保存时的任务、积分、宠物和库存记录。
4. 备份内含有照片时可以一并恢复；早期纯文字备份或备份中缺失的照片，无法在浏览器照片数据已清除后找回。

导入会替换当前记录，不会自动合并。当前仍有需要保留的数据时，应先下载一份新备份。备份之后新增且没有另行保存的记录无法从旧备份中恢复；换设备时也可以用同一份 JSON 文件导入。
