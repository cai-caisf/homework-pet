# 作业小宠物

完成作业打卡、收集积分，再领养和照顾虚拟小宠物的家庭网页工具。

网页地址：https://cai-caisf.github.io/homework-pet/

## 使用

- 添加作业，自定义每项作业的奖励积分（正整数，默认 10 分）。
- 布置作业时可以拍照或从相册选择最多 6 张参考照片；点击缩略图可放大、缩放和切换查看。
- 点击完成打卡后，弹窗核对作业和积分，二次确认再领取；取消不会加分，同一项作业只能领取一次。
- 用积分领养狗狗、小猫或兔兔，购买饲料、喂食和安排出游。
- 领养后在温馨房间里查看会呼吸、眨眼和摇尾巴的小动物；喂食时会低头吃东西、咀嚼并出现爱心。
- 可以切换不同宠物，查看饱饱度、开心度和小家的日记；互动动画期间防止重复消耗饲料或积分。
- 通过页脚下载 JSON 备份或恢复备份，备份包含作业照片，兼容旧版本的文字备份。

## 大人奖励

- 首页和作业打卡页均有“大人奖励”入口。连续答对两道随机混合计算题后，填写奖励积分（1–1000 的整数）和奖励原因，再确认发放。
- 每次奖励需要重新验证；通过后的本次操作 5 分钟内有效。答错会重新从第一题开始，累计答错三次暂停 30 秒，关闭弹窗或刷新不会清除暂停。
- 奖励原因显示在最近的小故事中；单独保留最近 100 笔奖励，奖励表单中显示最近 5 笔。奖励记录包含在 JSON 备份中，兼容旧版本备份。
- 计算题用于减少误操作，无法代替家长密码；会计算或使用计算器的孩子仍可能通过。

## 每周安排与限时打卡

- 作业打卡页提供周一至周日的日期栏，可切换上周、下周、任意日期并提前安排作业。首页只统计当天安排的作业。
- 添加作业时选择主日期，并勾选其他日期；也可一键选择“周一至周五”或“整周每天”。每一天生成独立作业，分别打卡、领取积分；相同参考照片共用一份本地图片存储。
- 可选勾选“设置可打卡时间段”。时间按安排日期及设备本地时间计算，开始时刻起可打卡，到结束时刻关闭，未开始或过期均不能领取积分。确认弹窗提交时也会再次检查时间。
- 结束时间早于开始时间时，表示次日结束；开始与结束不能相同。未设时间段的作业随时可完成，包括提前完成。
- 已有未注明日期的作业，在首次升级时归入当天且默认不限时，之后不会随日期漂移。原有积分、宠物、照片和完成记录保留；日期和时间段随备份一起保存。

## 照顾规则

- 开心度低于 50% 时禁止喂食，即使有饲料也不会消耗；达到 50% 后可喂食。白天去公园增加 18 点开心度，宠物乐园增加 26 点，上限 100%。
- 按设备本地时间，每天 22:30 起至次日 06:00 前睡觉，暂停喂食、出游、切换宠物和领养。睡眠期间可继续作业打卡、获得积分和购买饲料。
- 到 22:30 会停止当前互动动效并回到小家睡觉，不额外扣积分或饲料；06:00 自动恢复。网页重新打开、回到前台或设备时间变化时会重新检查。

## 宠物出游与睡姿

狗狗使用暖暖客厅、林荫公园和狗狗乐园；猫咪使用窗边小屋、花间公园和攀爬乐园，玩具为毛线球；兔兔使用花园小屋、草地公园和洞洞乐园，玩具为萝卜球。去公园花费 10 积分，宠物乐园花费 20 积分，小动物有对应的散步或玩耍动作。出游约 12 秒后自动回家，也可点击“回小家”提前结束，均只在出发时扣一次积分。出游期间禁用照顾和宠物切换，避免重复花费；切换到作业页后不会打断正在填写的草稿。

睡觉时使用单独绘制的趴卧形象：身体横卧、前爪垫在头下，配合缓慢呼吸和闭眼表情，三种动物均有对应睡姿。

积分不足时，不扣分也不进入出游，屏幕中央提示还差多少积分；该提示会自动消失。

## 数据

数据保存在当前设备、当前浏览器的本地存储中。不同设备和浏览器各自保存，不会自动同步；清除网站数据可能丢失记录，请定期下载备份。

作业照片适度压缩后保存在浏览器的 IndexedDB 中，图片最长边不超过 2048 像素，不会发送到服务器。手机的“拍照”入口由浏览器调用相机；电脑上可用文件选择器选图。

这个仓库只包含静态网页代码，不包含任何使用者的作业、积分或宠物记录。

## 文件

- `index.html`：网页入口
- `styles.css`：电脑和手机布局
- `app.js`：本地存储与应用功能
- `pet-room.css`：宠物房间和互动动画
- `.nojekyll`：让 GitHub Pages 直接发布静态文件
- `pet-art.js`：不同动物的场景、互动玩具和趴卧睡觉插画
